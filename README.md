# Sistema de Gestão de Brinquedos

## Funcionalidades (CRUD)

* Cadastrar, listar, editar e excluir brinquedos.
* **Campos:** nome, categoria, faixa etária, preço e estoque.

## Tecnologias

PHP, MySQL, HTML e XAMPP.

## Como Executar

1. Instale e inicie o Apache e o MySQL no **XAMPP**.
2. Mova a pasta do projeto para 'htdocs'.
3. No phpMyAdmin, importe o arquivo 'banco.sql'.
4. Confira as credenciais em 'config/conexao.php'.
5. Acesse no navegador: 'http://localhost/Gest-o-Brinquedos-Serasa/public/index.php'

## Estrutura Principal

* 'config' — Conexão com o banco de dados
* 'public' — Interface e páginas do sistema
* 'banco.sql' — Script de criação do banco e da tabela.
